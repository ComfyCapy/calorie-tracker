# Screenshot set

These stable, repository-relative images were captured from the live production application for the root README. They show the current dark-theme interface at a desktop viewport and exclude email addresses, credentials, health-profile values and other private account information.

| View | File | Capture notes |
| --- | --- | --- |

| Dashboard | `dashboard.jpg` | Nutrition cards, yearly heatmap and activity streak; 1440 × 720 |
| Daily diary | `diary.jpg` | Populated historical diary and daily summary; 1440 × 720 |
| Food catalogue | `foods.jpg` | Favourites and custom-food catalogue; 1440 × 720 |
| Achievements | `progress.jpg` | Level, activity and achievement progress; 1440 × 720 |
| Customisation | `customisation.jpg` | Layered avatar, cosmetic catalogue and equipped loadout; 1440 × 720 |

The authenticated captures use an existing production session. No foods, diary entries, cosmetics, profile data or other production records were changed to stage them. A Profile screenshot is intentionally omitted because the page displays personal health inputs; Achievements is used as the representative progress view instead.

When replacing these images, keep the stable filenames where practical, capture the live interface without browser chrome, and re-check every frame for personal information before committing it.
